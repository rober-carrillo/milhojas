# Milhojas brand

- `milhojas-mark.svg`: the logo. A milhoja in one line weight, bottom to top: puff pastry, piped cream, pastry, piped cream, and a tall wave of top cream as wide as the pastry. Pastry layers are rounded and a little wider so each layer stands out. No fills, one color.
- `milhojas-app-icon.svg`: simplified version on a dark tile for app icons and the browser tab (also `apps/web/app/icon.svg`).

Rules: 96 × 96 grid, line 2.75 units with round ends and corners. Color: amber `#b8740f` on light, `#e2a443` on dark; the name stays green-black `#18302a` (cream on dark). For one-color printing the mark can go green-black. The name is set in Bricolage Grotesque Bold. For screen printing or embroidery, convert the lines to outlines at the final size.

The web version with the drop animation is `apps/web/app/logo.tsx`.
